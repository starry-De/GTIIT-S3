# Thermodynamics I · Lecture 5 复习速查笔记：控制体（开口系统）质量与能量分析

## 1. 核心物理概念速查

### 1.1 控制体（Control Volume, CV）与边界交互
* **控制体（CV）**：空间中划定的固定或可变几何区域（如透平、泵、压缩机），工质允许跨越控制面（Control Surface）流入与流出。
* **跨界能量传递的三条途径**：热量交互（$\dot{Q}$）、机械功交互（$\dot{W}$），以及随进出质量流直接携带的外延能量。
* **稳态（Steady-State, SS）判据**：控制体内任意空间点的热力学性质不随时间变化，即蓄积项导数为零：
  $$\frac{dm_{cv}}{dt} = 0, \qquad \frac{dE_{cv}}{dt} = 0$$

### 1.2 流动功（Flow Work）与比焓（Enthalpy）的物理本质
* **流动功 $pv$**：流体跨过控制面时，必须克服进出口截面流体静压力做推挤功：
  * 入口外界推流体进门（输入功）：$\dot{W}_{\text{flow, in}} = (p_i A_i)V_i = \dot{m}_i (p_i v_i)$
  * 出口流体推外界出门（输出功）：$\dot{W}_{\text{flow, out}} = (p_e A_e)V_e = \dot{m}_e (p_e v_e)$
* **总功拆分**：$\dot{W} = \dot{W}_{cv} + \sum_e \dot{m}_e(p_e v_e) - \sum_i \dot{m}_i(p_i v_i)$。
* **比焓定义**：$h \equiv u + pv \quad [\text{kJ/kg}]$。
* **内能 $u$ vs. 比焓 $h$ 对照**：

| 参数 | 物理含义 | 核心适用场景 | 理想气体微分关系 |
| :--- | :--- | :--- | :--- |
| **比内能 $u$** | 分子微观热运动动能 + 分子间作用势能 | 闭口刚性容器（定容过程，$\Delta V = 0$） | $du = c_v dT$ |
| **比焓 $h$** | 流体自身内能 $u$ + 占位/跨界流动推挤功 $pv$ | 开口控制体流动、闭口定压膨胀过程 | $dh = c_p dT$ |

> **引入焓的目的**：将流体进出边界必然伴随的推挤功 $pv$ 打包进 $h$，使能量方程中的功项 $\dot{W}_{cv}$ 纯化为工程师直接关心的轴功或有用功。

## 2. 通用守恒母公式体系

### 2.1 质量守恒方程（Mass Rate Balance）
* **通用瞬态方程（多入口 $i$ / 多出口 $e$）**：
  $$\frac{dm_{cv}}{dt} = \sum_i \dot{m}_i - \sum_e \dot{m}_e$$
* **质量流量计算**：
  $$\dot{m} = \int_A \rho V_n \, dA \xrightarrow{\text{一维均匀流}} \dot{m} = \rho A V = \frac{A V}{v} \quad [\text{kg/s}]$$
* **稳态质量守恒**：
  $$\sum_i \dot{m}_i = \sum_e \dot{m}_e \quad \xrightarrow{\text{单进单出}} \quad \dot{m}_1 = \dot{m}_2 = \dot{m}$$

### 2.2 能量守恒方程（First Law for Control Volumes）
* **通用瞬态方程**：
  $$\frac{dE_{cv}}{dt} = \dot{Q} - \dot{W}_{cv} + \sum_i \dot{m}_i \left(h_i + \frac{V_i^2}{2} + gz_i\right) - \sum_e \dot{m}_e \left(h_e + \frac{V_e^2}{2} + gz_e\right)$$
* **稳态稳流方程（总功率形式）**：
  $$\dot{Q} + \sum_i \dot{m}_i \left(h_i + \frac{V_i^2}{2} + gz_i\right) = \dot{W}_{cv} + \sum_e \dot{m}_e \left(h_e + \frac{V_e^2}{2} + gz_e\right)$$
* **单进单出稳态方程（单位质量做题基准式）**：
  $$q - w_{cv} = (h_2 - h_1) + \frac{V_2^2 - V_1^2}{2000} + \frac{g(z_2 - z_1)}{1000} \quad [\text{kJ/kg}]$$
  *(注：$q = \dot{Q}/\dot{m}$，$w_{cv} = \dot{W}_{cv}/\dot{m}$；动能与势能除以 $1000$ 是为了从 $\text{J/kg}$ 统一为 $\text{kJ/kg}$；所有状态量均以差值出现，查表零点基准不影响结果。)*

## 3. 通用公式“四步剪裁法”（推导替代死记）

面对任何稳态设备，直接从**稳态能量母公式**出发，按顺序执行以下四步删减：

```
稳态母公式: Q_dot + ∑ m_i(h_i + V_i^2/2 + gz_i) = W_dot_cv + ∑ m_e(h_e + V_e^2/2 + gz_e)
             │
             ├─► 1. 数端口：1进1出则去掉 ∑ 并约去 m_dot；多流股则先列 ∑ m_i = ∑ m_e
             ├─► 2. 找转轴：无旋转叶片/活塞（管、阀、箱）──► 砍掉 W_dot_cv = 0
             ├─► 3. 看边界：保温良好或流速极快无暇换热 ───► 砍掉 Q_dot = 0
             └─► 4. 比量级：Δh 通常为数百 kJ/kg，远大于机械能变化：
                            • 高度差 gΔz ──► 除水坝外一律砍掉 (ΔPE ≈ 0)
                            • 动能差 ΔV²/2 ► 仅喷管/扩压管保留，其余设备一律砍掉 (ΔKE ≈ 0)
```

## 4. 六大典型稳态工程设备速查表

| 设备类型 | 物理功能与压力特征 | 剪裁条件 | 简化控制方程 | 关键考点与 $T\text{-}v$ 图特征 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 喷管 / 扩压管**<br>Nozzle / Diffuser | • 喷管：降压加速 ($p_1>p_2,\ V_2>V_1$)<br>• 扩压管：减速增压 ($p_1<p_2,\ V_2<V_1$) | $\dot{Q}=0,\ \dot{W}_{cv}=0$<br>$\Delta z \approx 0$<br>**保留 $\Delta KE$** | $h_1 + \frac{V_1^2}{2} = h_2 + \frac{V_2^2}{2}$<br>$V_2 = \sqrt{V_1^2 + 2000(h_1 - h_2)}$<br>*(式中 $h$ 单位为 $\text{kJ/kg}$)* | • 题型常结合 $\dot{m} = \frac{AV}{v}$ 求出口截面积 $A_2$。 |
| **2. 透平 / 涡轮机**<br>Turbine | 高压流体推动叶片膨胀对外输出轴功<br>• 最高压在**入口 1** ($p_1 > p_2$) | $\dot{Q}=0$<br>$\Delta KE, \Delta PE \approx 0$ | $\dot{W}_{cv} = \dot{m}(h_1 - h_2) > 0$ | • 散热会减小输出功，故**绝热透平**输出功最大。 |
| **3. 泵 / 压缩机**<br>Pump / Compressor | 消耗外界轴功提升流体压力<br>• 最高压在**出口 2** ($p_2 > p_1$) | $\dot{Q}=0$<br>$\Delta KE, \Delta PE \approx 0$ | $\dot{W}_{cv} = \dot{m}(h_1 - h_2) < 0$<br>$|\dot{W}_{\text{in}}| = \dot{m}(h_2 - h_1)$ | • **泵**（液体）：$T\text{-}v$ 图左侧压缩液区近乎**垂直短线**（$v$ 几乎不变）。<br>• **压缩机**（气体）：$T\text{-}v$ 图右侧过热区向左上**大幅攀升长斜线**（$T$ 剧增，$v$ 减小）。 |
| **4. 换热器**<br>Heat Exchanger | 冷热两股流体不混合进行热量传递 | $\dot{W}_{cv}=0$<br>$\Delta KE, \Delta PE \approx 0$ | • **框整体** ($\dot{Q}=0$)：<br>$\dot{m}_c(h_1-h_2)+\dot{m}_h(h_3-h_4)=0$<br>• **框单流道** ($\dot{Q}\neq 0$)：<br>$\dot{m}_h(h_3-h_4)+\dot{Q}=0$ | • $\dot{Q}$ 是否为零完全取决于**控制体虚线画在哪**。 |
| **5. 节流装置**<br>Throttling Valve | 流体经局部微孔/阀门不可逆降压 ($p_1 \gg p_2$) | $\dot{Q}=0,\ \dot{W}_{cv}=0$<br>$\Delta KE, \Delta PE \approx 0$ | $h_1 = h_2$（**等焓过程**） | • 高度不可逆，$T\text{-}v$ 图 1→2 必须画**虚线**。<br>• 理想气体等焓即等温 ($T_1=T_2$)；实际制冷剂进入两相区闪蒸，温度大幅暴跌。 |
| **6. 混合室**<br>Mixing Chamber | 两股流体直接混为一股均匀流体流出 | $\dot{Q}=0,\ \dot{W}_{cv}=0$<br>$\Delta KE, \Delta PE \approx 0$ | 质量：$\dot{m}_1 + \dot{m}_2 = \dot{m}_3$<br>能量：$\dot{m}_1 h_1 + \dot{m}_2 h_2 = \dot{m}_3 h_3$ | • 必须同时联立质量守恒与能量守恒方程求解。 |

## 5. 考场避坑与标准解题流

### 5.1 三大高频易错点
1. **功与热的符号规定**：本课程采用热力学标准约定——**系统吸热为正（$\dot{Q}>0$），系统对外输出功为正（$\dot{W}_{cv}>0$）**。计算泵或压缩机时，$\dot{W}_{cv} = \dot{m}(h_1 - h_2)$ 结果必为**负数**。
2. **量纲 1000 倍陷阱**：查表比焓 $h$ 单位为 $\text{kJ/kg}$，而 $\frac{V^2}{2}$ 与 $gz$ 单位为 $\text{J/kg}$。计算流速或功时**严禁直接相加**，必须先对动能/势能项除以 $1000$（或对 $\Delta h$ 乘以 $1000$）。
3. **物态查表区分**：
   * **湿蒸汽区（Two-phase）**：利用干度 $x$ 线性插值，$h = h_f + x h_{fg}$，$v = v_f + x v_{fg}$。
   * **理想气体（Ideal Gas）**：比焓仅取决于温度，$\Delta h = c_p (T_2 - T_1)$（常比热假设）或按温度查空气/燃气表。

### 5.2 标准四步解题流程
1. **划定边界与工况**：明确控制体范围（单部件或整体），确认稳态（$\sum \dot{m}_i = \sum \dot{m}_e$）。
2. **剪裁能量方程**：写出稳态能量母公式，按“数端口 $\rightarrow$ 找转轴 $\rightarrow$ 看边界 $\rightarrow$ 比量级”划掉零项。
3. **确定状态参数**：根据各端口的两个独立强度参数（如 $P, T$ 或 $P, x$），查表或用状态方程求出各口 $h, v$。
4. **代值与单位核验**：统一为 $\text{kJ/kg}$ 与 $\text{kW}$ 后求解未知量，检查功率正负号是否符合设备做功/耗功物理直觉。
