## 单变量非线性方程求根：二分法 (Solution of Equations in One Variable: Bisection Method)

---

## 一、 核心概念与数学定理 (Core Concepts & Theorems)

### 1.1 为什么需要数值求根？
* **核心问题**：给定函数 $f$，寻找实数 $p$ 使得 $f(p) = 0$。
* **解析解的局限性**：绝大多数非线性方程没有求根公式。例如五次及以上多项式没有根式解（Abel 定理, 1824），工程中的 Colebrook 摩擦系数方程将未知数隐含在对数内。
* **数值解的三大构成要素**（缺一不可）：
  1. **逼近序列 (Sequence)**：仅利用函数值生成的近似解序列 $p_1, p_2, \dots$。
  2. **停机准则 (Stopping Rule)**：经过 $n$ 步迭代后，满足 $\vert{}p_n - p\vert{} \le \epsilon$。
  3. **先验误差界 (Error Bound)**：在计算第一个函数值之前就能确定的误差上限。

### 1.2 根的存在性：介值定理 (Intermediate Value Theorem, IVT)
* **定理 1.11 (IVT)**：若函数 $f$ 在闭区间 $[a, b]$ 上连续，且 $K$ 为介于 $f(a)$ 和 $f(b)$ 之间的任意实数，则存在 $c \in (a, b)$ 使得 $f(c) = K$。
* **求根特例 ($K=0$)**：若 $f \in C[a, b]$ 且端点函数值异号（即 $f(a) \cdot f(b) < 0$），则开区间 $(a, b)$ 内**至少存在一个根** $p$。
* **两个关键前提与常见误区**：
  1. **连续性是前提 (Continuity comes first)**：如果函数不连续（存在跳跃间断点 jump 或奇点 pole），即使 $f(a) \cdot f(b) < 0$，区间内也可能根本没有根。
  2. **变号是充分非必要条件**：重根（如 $f(x) = (x-1)^2$ 在 $x=1$ 处）接触零点但不穿过零点（不变号），无法用二分法的有根区间（Bracket）捕获。
  3. **职责划分**：二分法程序本身通常不检查连续性和端点异号，验证 $[a, b]$ 是合法有根区间是建模者的工作。

### 1.3 根的唯一性：微分中值定理与导数判别法
* **罗尔定理 (Rolle's Theorem)**：若 $f$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，且 $f(a) = f(b)$，则存在 $c \in (a, b)$ 使得 $f'(c) = 0$。
* **拉格朗日中值定理 (Mean Value Theorem)**：在相同条件下，存在 $c \in (a, b)$ 使得 $f'(c) = \frac{f(b) - f(a)}{b - a}$。
* **单调性唯一根判别 (Derivative Test)**：若在 $(a, b)$ 上恒有 $f'(x) > 0$（严格单调递增）或恒有 $f'(x) < 0$（严格单调递减），则 $f$ 在 $[a, b]$ 上**至多有一个根**。
* **存在且唯一**：**IVT（端点异号）+ 导数保号（单调性）= 区间内存在唯一实根**。

## 二、 二分法算法实现 (Algorithm 2.1: Bisection Method)

### 2.1 算法伪代码与细节
* **输入 (INPUT)**：区间端点 $a, b$；容差 $TOL$；最大迭代次数 $N_0$。
* **输出 (OUTPUT)**：近似解 $p$，或失败提示信息。
* **算法步骤**：
  * **Step 1**：初始化 $i = 1$，$FA = f(a)$。
  * **Step 2**：当 $i \le N_0$ 时，循环执行 Steps 3–6：
  * **Step 3**：计算中点 $p = a + \frac{b - a}{2}$（防止浮点溢出的安全写法），计算 $FP = f(p)$。
  * **Step 4**：若 $FP = 0$ 或 $\frac{b - a}{2} < TOL$，则输出 $p$ 并终止程序 (STOP)。
  * **Step 5**：更新迭代计数 $i = i + 1$。
  * **Step 6**：若 $FA \times FP > 0$（说明 $a$ 与 $p$ 同号，根在右半区间），令 $a = p, \ FA = FP$；否则（根在左半区间），令 $b = p$。
  * **Step 7**：若超出循环，输出 `'failed after N0 iterations'` 并终止。
* **四个工程实现细节**：
  1. 算法默认假设 $f(a) \cdot f(b) < 0$，内部不做额外检查。
  2. **每次迭代仅需计算 1 次新的函数值** $f(p)$，全程不需要计算 $f(b)$。
  3. Step 4 停机条件绝对安全，因为中点 $p$ 到真实根的距离至多为半区间长度 $\frac{b-a}{2}$。
  4. 最大迭代次数 $N_0$ 用于防止当 $TOL$ 设置得比机器精度还小时陷入死循环。

### 2.2 Python 标准实现代码

```python
def bisect(f, a, b, tol=1e-5, N0=100):
    fa = f(a)                           # Step 1
    for n in range(1, N0 + 1):          # Step 2
        p = a + (b - a) / 2             # Step 3: 计算中点
        fp = f(p)
        if fp == 0 or (b - a) / 2 < tol: # Step 4: 停机判断
            return p, n
        if fa * fp > 0:                 # Step 6: 选择保留变号的一半区间
            a, fa = p, fp
        else:
            b = p
    raise RuntimeError("not converged") # Step 7

# 调用示例：求解 x^3 + x - 1 = 0 在 [0, 1] 上的根
f = lambda x: x**3 + x - 1
p, n = bisect(f, 0.0, 1.0)
print(f"p = {p:.6f} after {n} steps")   # 输出: p = 0.682328 after 17 steps
```

## 三、 先验误差界与停机准则分析 (Error Bound & Stopping Criteria)

### 3.1 定理 2.1：二分法先验误差界
* **定理内容**：设 $f \in C[a, b]$ 且 $f(a) \cdot f(b) < 0$。二分法生成的近似序列 $\{p_n\}$ 对任意 $n \ge 1$ 满足：
  $$\vert{}p_n - p\vert{} \le \frac{b - a}{2^n}$$
* **核心性质**：该误差界是**先验的 (a priori)**——它只取决于初始区间宽度 $(b - a)$ 和迭代次数 $n$，**与函数 $f(x)$ 的具体形式完全无关**！（注意：实际误差 $\vert{}p_n - p\vert{}$ 会在误差界曲线下方呈锯齿状波动下降。）

### 3.2 迭代次数 $n$ 的预估公式
要保证绝对误差严格小于给定的容差 $\epsilon$（即 $TOL$），只需令先验误差界小于 $\epsilon$：
$$\frac{b - a}{2^n} < \epsilon \implies 2^n > \frac{b - a}{\epsilon} \implies n > \frac{\log\left(\frac{b - a}{\epsilon}\right)}{\log 2} = \log_2\left(\frac{b - a}{\epsilon}\right)$$
* **常用经验数字**：
  * 初始区间宽度为 $1$、精度要求 $\epsilon = 10^{-4}$ 时，需要 $n = 14$ 步。
  * **每提高 1 位十进制有效数字（精度提高 10 倍）**，需要增加 $\log_2 10 \approx 3.32$ 次二分迭代。
  * **双精度浮点数 (Double Precision)** 的极限：对单位区间二分约 $52$ 次后达到机器精度极限（因为 $2^{-52} \approx 2.2 \times 10^{-16}$）。

### 3.3 三种停机准则与两大陷阱
> [!IMPORTANT]
>1. **三种常见判据**：
>   * **绝对误差判据** $\vert{}p_n - p\vert{} < \epsilon$：真实解 $p$ 未知，实际不可直接计算。
>   * **残差判据 (Residual)** $\vert{}f(p_n)\vert{} < \epsilon$：计算代价低，但在函数图像平坦处极其不可靠。
>   * **步长判据 (Step size)** $\vert{}p_n - p_{n-1}\vert{} < \epsilon$：对于二分法，有 $\vert{}p_n - p_{n-1}\vert{} = \frac{b - a}{2^n}$，**步长恰好等于先验误差界**！因此二分法可以直接用步长（或半区间宽）作为可靠的停机条件（注：牛顿法不具备此性质）。
2. **两大常见陷阱 (Two Traps)**：
   * **陷阱一（小残差 $\neq$ 小误差）**：由中值定理知 $\text{误差} \approx \frac{\text{残差}}{\text{斜率 } f'}$。当函数图像非常平坦（$\vert{}f'\vert{}$ 极小）时，很小的残差 $\vert{}f(p_n)\vert{}$ 背后可能隐藏着巨大的解误差。
   * **陷阱二（奇点伪根）**：函数在垂直渐近线/极点（pole，如 $f(x) = \frac{1}{x}$ 在 $x=0$ 两侧）也会发生符号改变，二分法会把无定义的奇点误判为“根”。因此停机后必须验证 $\vert{}f(p_n)\vert{}$ 确实趋近于 $0$。

## 四、 经典例题全解析 (Worked Examples 1–8)

### Example 1：存在性验证与前三次手算迭代
> **题目**：(a) 验证方程 $\ln(1+x) - \cos x = 0$ 在 $(0, 1)$ 上有根。(b) 使用二分法求第 3 次近似值 $p_3$ 以及下一个包含根的区间 $[a_4, b_4]$。

* **解答**：
  * **(a) 存在性证明**：设 $f(x) = \ln(1+x) - \cos x$。函数在 $[0, 1]$ 上连续。计算端点值：
    $$f(0) = \ln(1) - \cos(0) = 0 - 1 = -1 < 0$$
    $$f(1) = \ln(2) - \cos(1) \approx 0.69315 - 0.54030 = +0.15285 > 0$$
    因为 $f(0) \cdot f(1) < 0$，由介值定理 (IVT) 知在 $(0, 1)$ 内至少存在一个实根。
  * **(b) 逐步二分迭代**：
    * **$n = 1$**：区间 $[a_1, b_1] = [0, 1]$，中点 $p_1 = 0.5$。
      $$f(0.5) = \ln(1.5) - \cos(0.5) \approx 0.40547 - 0.87758 = -0.47211 < 0$$
      因 $f(0.5) < 0$ 且 $f(1) > 0$，更新区间为 $[a_2, b_2] = [0.5, 1]$。
    * **$n = 2$**：区间 $[0.5, 1]$，中点 $p_2 = 0.75$。
      $$f(0.75) = \ln(1.75) - \cos(0.75) \approx 0.55962 - 0.73169 = -0.17207 < 0$$
      因 $f(0.75) < 0$ 且 $f(1) > 0$，更新区间为 $[a_3, b_3] = [0.75, 1]$。
    * **$n = 3$**：区间 $[0.75, 1]$，中点 **$p_3 = 0.875$**。
      $$f(0.875) = \ln(1.875) - \cos(0.875) \approx 0.62861 - 0.640996 = -0.01239 < 0$$
      因 $f(0.875) < 0$ 且 $f(1) > 0$，下一个包络区间为 **$[a_4, b_4] = [0.875, 1]$**。

### Example 2：先算步数，再迭代
> **题目**：在 $0 \le x \le 1$ 上用二分法求 $x - 2^{-x} = 0$ 的解，精确到 $10^{-5}$ 以内。

* **解答**：
  1. **验证有根区间**：设 $f(x) = x - 2^{-x}$，在 $[0, 1]$ 上连续。$f(0) = -1 < 0$，$f(1) = 0.5 > 0$，满足异号条件。
  2. **计算所需步数 $n$**：初始区间宽 $b - a = 1$，容差 $\epsilon = 10^{-5}$：
     $$\frac{1}{2^n} < 10^{-5} \implies 2^n > 10^5 \implies n > \log_2(10^5) = \frac{5}{\log_{10} 2} \approx 16.61 \implies \mathbf{n = 17}$$
     固定迭代 **17 步**即可严格保证精度。
  3. **迭代结果**：经过 17 次二分后，得到近似解 **$p_{17} \approx 0.641186$**（区间缩小至宽度为 $2^{-17} \approx 7.63 \times 10^{-6} < 10^{-5}$）。

### Example 3：窄初始区间的优势 (A Narrow Bracket)
> **题目**：在 $0.2 \le x \le 0.3$ 上用二分法求 $x \cos x - 2x^2 + 3x - 1 = 0$ 的解，精确到 $10^{-5}$ 以内。

* **解答**：
  1. **验证有根区间**：$f(0.2) \approx -0.28399 < 0$，$f(0.3) \approx +0.00660 > 0$，满足条件。
  2. **计算所需步数 $n$**：得益于较窄的初始区间 $b - a = 0.3 - 0.2 = 0.1$，所需步数显著减少：
     $$\frac{0.1}{2^n} < 10^{-5} \implies 2^n > 10^4 \implies n > \log_2(10^4) \approx 13.29 \implies \mathbf{n = 14}$$
     相比单位区间节省了 3 次迭代（因为区间缩小为 $1/10$，节省了 $\log_2 10 \approx 3.32$ 步）。
  3. **迭代结果**：第 14 次迭代中点为 **$p_{14} \approx 0.297528$**，误差上限为 $\frac{0.1}{2^{14}} \approx 6.10 \times 10^{-6} < 10^{-5}$。

### Example 4：微积分先行，二分法置后 (Calculus First, Bisection Second)
> **题目**：已知方程 $\frac{3}{2}x - 6 - \frac{1}{2}\sin(2x) = 0$ 有唯一实根。(a) 找出一个保证包含该唯一实根的区间。(b) 使用二分法将该根近似到绝对容差 $10^{-5}$ 以内。

* **解答**：
  * **(a) 微积分分析与定位区间**：
    设 $f(x) = \frac{3}{2}x - 6 - \frac{1}{2}\sin(2x)$。
    * **唯一性证明**：求导得 $f'(x) = \frac{3}{2} - \cos(2x)$。因为 $\cos(2x) \le 1$，所以对任意 $x \in \mathbb{R}$ 恒有 $f'(x) \ge \frac{1}{2} > 0$。函数在 $\mathbb{R}$ 上严格单调递增，故至多有一个实根。
    * **构造有根区间 (Bracket)**：利用有界性 $\vert{}\sin(2x)\vert{} \le 1$ 进行放缩估值：
      当 $\frac{3}{2}x - 6 \approx 0 \implies x \approx 4$ 时函数接近零点。尝试整数端点 $[3, 5]$（或 $[3, 4]$、$[4, 5]$）：
      * $f(3) = 4.5 - 6 - 0.5\sin(6) = -1.5 - 0.5\sin(6) \le -1.5 + 0.5 = -1 < 0$
      * $f(4) = 6 - 6 - 0.5\sin(8) = -0.5\sin(8) \approx -0.49468 < 0$
      * $f(5) = 7.5 - 6 - 0.5\sin(10) = 1.5 - 0.5\sin(10) \ge 1.5 - 0.5 = +1 > 0$
      因此，可取单位长度区间 **$[4, 5]$**（或无需计算正弦值即可严格放缩证明异号的 **$[3, 5]$**）。
  * **(b) 二分法求解**：
    * 若取 $[4, 5]$（宽度为 1）：需 $n = 17$ 步（因为 $2^{-17} < 10^{-5}$）。
    * 若取 $[3, 5]$（宽度为 2）：$\frac{2}{2^n} < 10^{-5} \implies 2^{n-1} > 10^5 \implies n = 18$ 步。
    * 最终收敛到的近似根为 **$p \approx 4.274782$**。

### Example 5：离散有序集合上的二分法（二分查找 Binary Search）
> **题目**：给定升序排列的整数数组 `nums` 和目标整数 `target`，使用二分技术查找 `target` 的下标，不存在则返回 `-1`。

* **核心思想**：二分法的本质不需要连续代数函数，只需要一个**有序集合 (Ordered Set)** 和一个**每次能排除一半空间的判定条件**。
* **Python 实现**：

```python
def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2  # 整数中点
        if nums[mid] == target:
            return mid                    # 命中目标
        elif nums[mid] < target:
            left = mid + 1                # 目标在右半部分
        else:
            right = mid - 1               # 目标在左半部分
    return -1                             # 未找到
```

### Example 6：多根方程的单区间捕获
> **题目**：方程 $e^x = 3x$ 有两个正实根。(a) 在 $[0, 1]$ 上使用二分法，需要多少步才能保证误差小于 $10^{-4}$？(b) 计算前三次近似值 $p_1, p_2, p_3$。

* **解答**：
  * **方程转化**：设 $f(x) = e^x - 3x$。两个正根分别位于 $[0, 1]$ 内（约 $0.619$）和 $[1, 2]$ 内（约 $1.512$）。**一个有根区间 $[0, 1]$ 只能认证并收敛到其中的那一个根**。
  * **(a) 步数计算**：区间 $[0, 1]$ 宽度为 $1$，容差 $\epsilon = 10^{-4}$：
    $$\frac{1}{2^n} < 10^{-4} \implies 2^n > 10000 \implies n > 13.2877 \implies \mathbf{n = 14}$$
    （注：$2^{13} = 8192$，$2^{14} = 16384$，故需 **14 步**。）
  * **(b) 前三次迭代计算**：
    先算端点：$f(0) = e^0 - 0 = 1 > 0$，$f(1) = e^1 - 3 \approx -0.28172 < 0$。
    * **$n = 1$**：$[0, 1] \implies \mathbf{p_1 = 0.5}$，$f(0.5) = e^{0.5} - 1.5 \approx 1.64872 - 1.5 = +0.14872 > 0$。根在 $[0.5, 1]$。
    * **$n = 2$**：$[0.5, 1] \implies \mathbf{p_2 = 0.75}$，$f(0.75) = e^{0.75} - 2.25 \approx 2.11700 - 2.25 = -0.13300 < 0$。根在 $[0.5, 0.75]$。
    * **$n = 3$**：$[0.5, 0.75] \implies \mathbf{p_3 = 0.625}$，$f(0.625) = e^{0.625} - 1.875 \approx 1.86825 - 1.875 = -0.00675 < 0$。下一个区间为 $[0.5, 0.625]$。

### Example 7：初始区间决定收敛到哪个根
> **题目**：函数 $f(x) = \sin(\pi x)$ 在每个整数处都为零。(a) 在 $[0.5, 1.5]$ 和 $[1.5, 2.5]$ 上运行二分法，分别得到哪个根？(b) 如果从 $[0.5, 2.5]$ 开始会发生什么？

* **解答**：
  * **(a)**：
    * 在 $[0.5, 1.5]$ 上：$f(0.5) = \sin(0.5\pi) = +1 > 0$，$f(1.5) = \sin(1.5\pi) = -1 < 0$。第一步中点 $p_1 = \frac{0.5 + 1.5}{2} = \mathbf{1.0}$，直接命中 $f(1.0) = \sin(\pi) = 0$，算法在第 1 步立即终止并返回根 **$x = 1$**。
    * 在 $[1.5, 2.5]$ 上：$f(1.5) = -1 < 0$，$f(2.5) = +1 > 0$。第一步中点 $p_1 = \frac{1.5 + 2.5}{2} = \mathbf{2.0}$，$f(2.0) = 0$，直接命中并返回根 **$x = 2$**。
  * **(b)**：当初始区间为 $[0.5, 2.5]$ 时：
    * **数学合法性角度**：$f(0.5) = +1 > 0$ 且 $f(2.5) = +1 > 0$，**端点同号 ($f(a)\cdot f(b) > 0$)**，违反了二分法的初始有根区间假设（区间内包含了偶数个根 $x=1$ 和 $x=2$，正负抵消）。
    * **代码实际执行角度**（按 Algorithm 2.1 逻辑）：
      1. 第 1 步计算中点 $p_1 = \frac{0.5 + 2.5}{2} = 1.5$，$f(1.5) = -1 < 0$。
      2. 判断 `FA * FP`：$f(0.5) \times f(1.5) = (+1) \times (-1) < 0$，走 `else` 分支令 $b = p_1 = 1.5$，区间变为 $[0.5, 1.5]$（此时意外恢复成了合法异号区间！）。
      3. 第 2 步计算中点 $p_2 = \frac{0.5 + 1.5}{2} = \mathbf{1.0}$，命中 $f(1.0) = 0$，收敛到 **$x = 1$**（漏掉了 $x = 2$）。
    * **核心结论**：**是初始区间（Bracket）选择了根，算法只是忠实地执行该选择**。

### Example 8：工程物理建模与二分法求解
> **题目**：一个半径 $r = 1\text{ ft}$、长度 $L = 10\text{ ft}$ 的水平半圆柱形水槽（或圆柱形槽），装有体积 $V = 5\text{ ft}^3$ 的水。建立关于水深 $h$ 的方程，并用二分法求水深 $h$，精确到 $0.01\text{ ft}$ 以内。

* **解答**：
  1. **几何物理建模 (Building the Equation)**：
     设水深为 $h$（满足 $0 \le h \le r = 1$）。水面距离圆心的垂直距离为 $d = r - h$。
     由圆心到水面的垂线构成的半角为 $\theta = \arccos\left(\frac{r - h}{r}\right)$。
     * 扇形面积：$A_{\text{sector}} = r^2 \theta = r^2 \arccos\left(\frac{r - h}{r}\right)$
     * 上方三角形面积：$A_{\text{triangle}} = (r - h)\sqrt{r^2 - (r - h)^2} = (r - h)\sqrt{2rh - h^2}$
     * 浸水弓形截面积：$A(h) = A_{\text{sector}} - A_{\text{triangle}}$
     * 水体体积方程：$V = L \cdot A(h) = L \left[ r^2 \arccos\left(\frac{r - h}{r}\right) - (r - h)\sqrt{2rh - h^2} \right]$
     代入已知参数 $r = 1, \ L = 10, \ V = 5$，构造求根函数 $f(h) = 0$：
     $$f(h) = 10 \left[ \arccos(1 - h) - (1 - h)\sqrt{2h - h^2} \right] - 5 = 0$$
     （或两边同除以 10 化简为：$g(h) = \arccos(1 - h) - (1 - h)\sqrt{2h - h^2} - 0.5 = 0$。）
  2. **确定初始有根区间 $[a, b]$**：
     根据物理意义，水深在全空 $h = 0$ 到半满 $h = r = 1$ 之间：
     * $f(0) = 10 [0 - 0] - 5 = -5 < 0$
     * $f(1) = 10 \left[\frac{\pi}{2} - 0\right] - 5 = 5\pi - 5 \approx +10.708 > 0$
     故合法初始区间为 **$[0, 1]$**。
  3. **计算所需二分步数 $n$**：
     区间宽度 $b - a = 1$，容差 $\epsilon = 0.01$：
     $$\frac{1}{2^n} < 0.01 \implies 2^n > 100 \implies \mathbf{n = 7} \quad (\text{因为 } 2^6 = 64, \ 2^7 = 128)$$
  4. **7 步二分迭代过程表**：

     | 步数 $n$ | 左端点 $a_n$ | 右端点 $b_n$ | 中点 $h_n$ | $f(h_n)$ 的值与符号 | 半区间误差界 |

| 核心考点 | 关键公式 / 判据 | 易错点与注意事项 |
| :--- | :--- | :--- |
| **存在性证明** | $f \in C[a, b]$ 且 $f(a) \cdot f(b) < 0$ | 必须先写明**函数连续**，再算端点异号；重根和奇点需警惕 |
| **唯一性证明** | $f'(x) > 0$ 或 $f'(x) < 0$ 在 $(a, b)$ 上恒成立 | 结合 IVT 才能得出“存在唯一实根” |
| **先验误差界** | $\|p_n - p\| \le \frac{b - a}{2^n}$ | 仅与初始区间宽 $(b-a)$ 和步数 $n$ 有关，与函数 $f$ 无关 |
| **迭代步数预估** | $n > \log_2\left(\frac{b - a}{\epsilon}\right) = \frac{\ln((b-a)/\epsilon)}{\ln 2}$ | 向上取整；每增加 1 位有效数字约需 $3.32$ 步 |
| **安全中点公式** | $p_n = a_n + \frac{b_n - a_n}{2}$ | 优于 $(a_n+b_n)/2$，避免大数相加溢出且保证中点落在区间内 |
| **可靠停机判据** | $\frac{b_n - a_n}{2} < TOL$ （等价于 $\|p_n - p_{n-1}\| < TOL$） | 切勿单独依赖残差 $\|f(p_n)\| < TOL$ 停机 |
